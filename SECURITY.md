# Security Policy

## Supported Versions

Only the latest release of Subscription Leak Finder receives security fixes.

## Reporting a Vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, report it privately via [GitHub Security Advisories](https://github.com/CocoCrypto03/subscription-leak-finder/security/advisories/new) for this repository.

Include as much detail as possible:

- A description of the vulnerability and its impact
- Steps to reproduce
- Any suggested fix, if you have one

We aim to acknowledge reports within 48 hours and to release a fix or
mitigation within a reasonable timeframe depending on severity.

Thank you for helping keep Subscription Leak Finder and its users safe.
